# 🌱 BrainBloom — Middle School Mind Games

**Think fast. Spot patterns. Have fun learning.**

BrainBloom is a responsive, browser-based collection of quick games designed for students in **Classes 6–8**. It’s a simple learning demo that runs locally—no installation, account, API key, or internet connection needed.

## 🎮 Games included

- **Memory Match** — exercise your memory and concentration.
- **Math Sprint** — solve quick math challenges.
- **Pattern Detective** — find the rule and complete the pattern.
- **Number Ninja** — sharpen your number skills.
- **Riddle Room** — think creatively to solve brain teasers.
- **Speed Round** — challenge yourself to answer before time runs out.

## 🚀 Get started

1. Open the `IQ-MATH` repo.
2. Double-click `index.html` to launch it in Chrome, Edge, or Firefox.
3. Pick a game and start playing!

> No setup or server required. The games run right in your browser.

## 📊 Progress and privacy

Scores are saved in your browser with `localStorage`, so they stay on that device and browser. Select **Reset progress** to clear them. BrainBloom has no student accounts, cloud storage, teacher dashboards, or online leaderboards.

## 🧩 About this project

BrainBloom is a learning and demonstration project for middle-school mind games. It is not a hosted service or a student-management platform.
